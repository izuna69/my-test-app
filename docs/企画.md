# 📅 윈도우 데스크탑 캘린더 앱 홍보 웹사이트 기획서

---

## 1. 프로젝트 개요 (Overview)
* **목적**: 직접 개발한 Windows 데스크탑 캘린더 프로그램(`.exe`)을 소개하고 다운로드를 유도하는 제품 랜딩 페이지 제작
* **성격**: 개인 학습 및 실습 프로젝트

---

## 2. 제품 정보 (Product)
* **제품명**: 데스크탑 캘린더 & 스케줄러
* **형태**: Windows 데스크탑 설치형 프로그램 (`.exe`)
* **주요 특징**:
  * Windows 시스템 트레이 상주 및 빠른 열기/닫기
  * PC 부팅 시 자동 시작 (`--autostart`) 지원
  * 중요 일정 및 마감일 스마트 팝업 알림
  * Material 3 기반의 모던 UI & 다크 모드 지원
  * 로컬 스토리지 기반 오프라인 동작 및 개인정보 보호

---

## 3. 기술 스택 (Tech Stack)
* **Core**: React 19, Vite, TypeScript/JavaScript
* **Styling**: Tailwind CSS
* **Data Visualization**: ECharts (`echarts-for-react` / `echarts`)
* **Routing**: React Router (`react-router-dom`)

---

## 4. 협업 규칙 및 AI 역할 (Ground Rules)
> ⚠️ **학습 목적 준수**
> * **"코딩해줘"라고 명시적으로 요청하기 전까지 AI는 소스 코드를 대신 작성하지 않는다.**
> * **AI의 역할**:
>   1. 구조 설계, 모범 사례(Best Practices) 및 아키텍처 가이드
>   2. 비효율적인 방식이나 잘못된 접근에 대한 피드백 및 트러블슈팅
>   3. 웹사이트 기획, 콘텐츠 구성 및 차트 아이디어 추천
